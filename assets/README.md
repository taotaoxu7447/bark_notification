# Source icon provenance

- `deepseek-icon-v1.png` and `omp-icon-v1.png` are the original PNG files
  supplied by the user for DeepSeek Harness and OMP. Android large icons and
  Bark use these files unchanged. Bark copies are served at
  `https://aw.taotaoxu.net/icons/`.
- The monochrome DeepSeek notification glyph uses the whale path from the
  local DeepSeek Harness source's `apps/desktop/resources/icon.svg`.
  OMP's monochrome glyph preserves the supplied pixel π silhouette.

- `pi-icon-v1.svg` reproduces the square Pi mark distributed through the
  [official Pi press kit](https://pi.dev/press-kit). `pi-icon-v1.png` is the
  rasterized notification asset generated from that SVG.
- `opencode-icon-v1.svg` places the unmodified light OpenCode logo from the
  [official OpenCode brand archive](https://opencode.ai/brand) on a square
  neutral background. `opencode-icon-v1.png` is the rasterized notification
  asset generated from that SVG.

The project names and logos remain the property of their respective owners.
